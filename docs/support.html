Pulse 技术支持

常见问题

如何添加新习惯？

点击右上角的 + 按钮，输入习惯名称，选择图标、颜色和频率，然后保存即可。免费版最多添加3个习惯。

如何打卡？

在"今日"页面，点击习惯卡片即可完成打卡。你也可以左滑习惯快速打卡。

如何添加桌面小组件？

长按主屏幕 → 点击左上角 + → 搜索 "Pulse" → 选择小号或中号Widget → 添加到主屏幕。

Pro版包含什么？

  • 无限习惯数量（免费版限3个）
  • 10+精美Widget主题
  • iCloud多设备同步
  • CSV数据导出
  • 深色/渐变色主题

如何恢复Pro购买？

打开 Pulse → 设置 → 恢复购买。确保使用购买时的同一 Apple ID 登录。

如何导出数据？

Pro用户：设置 → 数据 → 导出为CSV → 选择分享方式。

数据会丢失吗？

不会。免费版数据存储在本地。Pro版自动通过iCloud同步。删除App不会自动删除iCloud数据，重新下载并登录同一Apple ID即可恢复。
